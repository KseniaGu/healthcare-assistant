# Maintained CA1 evaluation

The evaluator selects synthetic validation (64 fictitious cases), real development (13), or real reserved (11). Real cases come from a separate private role-only bundle. It uses the accepted packet's prompt, schema, and tokenizer; one pinned base with the selected adapter toggled on/off; NF4/BF16, greedy unconstrained generation, EOS stopping, and exact scoring without string normalization. D0018 alone has a 16,384-token total budget; all others use 8,192. Saved cases and settings are validated before resume skips them.
